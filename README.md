# Claude

A playground repository for working with Claude Code.

## Getting started

Clone the repository:

```sh
git clone https://github.com/vedeo-editor-saif/claude.git
cd claude
```

## Contributing

1. Create a branch: `git checkout -b my-change`
2. Commit your changes: `git commit -m "Describe the change"`
3. Push the branch: `git push -u origin my-change`
4. Open a pull request on GitHub.
